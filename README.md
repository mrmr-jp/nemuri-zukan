# ねむりの図鑑 / The Sleep Almanac

自分の1日の睡眠時間を入力すると、現存の動物や絶滅した生き物の睡眠時間とくらべられるWebアプリです。

**▶ アプリを開く：https://mrmr-jp.github.io/nemuri-zukan/**

アカウント登録は不要です。スマホでもPCでも、ブラウザで開くだけで使えます。

## できること

| タブ | 内容 |
|---|---|
| 🌙 くらべる | 睡眠時間（または寝た時刻・起きた時刻）を入力すると、近い生き物を3種表示。結果カードを画像で保存・シェアできる。「今日の一匹」も表示 |
| ❓ クイズ | 「どっちが長く眠る？」の2択クイズ。答えると豆知識が出て、図鑑に登録される |
| 📋 いちらん | 124種を睡眠時間の長い順に一覧表示。なかま（哺乳類・鳥類など）で絞り込める |
| 📖 図鑑 | 出会った生き物のコレクション。レア度（★1〜3）つき |

日本語と英語を切り替えられます。ダークモードにも対応しています。

## 構成

- `index.html` の1ファイルだけで動きます（HTML・CSS・JavaScriptをすべて含む）。
- サーバーやデータベースはありません。GitHub Pagesでそのまま公開しています。
- 外部から読み込んでいるのは Google Fonts だけです。

| ファイル | 内容 |
|---|---|
| `index.html` | アプリ本体 |
| `docs/design.md` | 設計書（機能・データ・ルール・変更履歴） |
| `docs/operation.md` | 運用手順書（更新・公開・確認・トラブル対処） |
| `CLAUDE.md` | Claude Code向けの開発メモ |

## プライバシー

入力した睡眠時間、図鑑の記録、クイズの成績は、使っている端末のブラウザの中にだけ保存されます。外部には送信しません。

## 注意事項

- このアプリは医療・健康上の助言を目的としたものではありません。
- 生き物の睡眠時間には、学術文献の値のほか、一般的な紹介値や推定値（絶滅種など）を含みます。値ごとに出典と信頼度をアプリ内に表示しています。
