# ねむりの図鑑 設計書

最終更新：2026-10-08

この設計書は、アプリの「何を・どう作っているか」をまとめたものです。修正を頼むときや、しばらく触っていなかったあとに見返すときに使います。

---

## 1. 概要

| 項目 | 内容 |
|---|---|
| 名前 | ねむりの図鑑 / The Sleep Almanac |
| 目的 | 自分の睡眠時間を、生き物の睡眠時間とくらべて楽しむ |
| 対象 | 誰でも（アカウント不要・スマホ中心） |
| 公開URL | https://mrmr-jp.github.io/nemuri-zukan/ |
| リポジトリ | `mrmr-jp/nemuri-zukan`（Public） |
| 構成 | `index.html` 1ファイル。サーバー・DB・ビルドなし |
| 言語 | 日本語／英語（切替式） |

Claude上にも別の公開版（ねむりの図鑑（Claude））があります。**GitHub Pages版とClaude版は別物で、片方を更新してももう片方は変わりません。**

## 2. 画面構成

画面下のタブバーで、4つのページを切り替えます。実際にはページを移動せず、表示・非表示を切り替えているだけです（`showTab()`）。

```
┌───────────────────────┐
│  🌙くらべる ❓クイズ 📋いちらん 📖図鑑  │ ← タブバー
└───────────────────────┘
        ＋ 詳細ダイアログ（生き物の豆知識）
        ＋ シークレット（隠し要素）
```

| ページ | `data-page` | 主な要素 |
|---|---|---|
| くらべる | `home` | 睡眠ダイヤル、時間入力（スライダー／±15分・30分ボタン）、時刻入力（寝た・起きた）、近い生き物3種、結果カード、今日の一匹 |
| クイズ | `quiz` | 2択（どっちが長く眠る？）、正解時の豆知識、成績 |
| いちらん | `list` | 全種の一覧、なかまフィルター（すべて／哺乳類／鳥類／爬虫類／両生類／魚類／昆虫） |
| 図鑑 | `zukan` | 発見済みコレクション、レア度、ランダムに出会う、出典・注意事項・プライバシー |

## 3. 機能一覧

| 機能 | 内容 | 主な関数 |
|---|---|---|
| 睡眠時間の入力 | 時間（0〜24時間）または寝た・起きた時刻から計算。日付をまたいでも計算する | `setH` `fromClock` |
| 近い生き物 | 入力した時間に近い順に3種を表示し、ひとこと判定を出す | `render` `verdict` |
| 結果カード | 近い3種から1種を選び、画像（PNG）を生成して保存・シェア | `makeCard` `renderCardPanel` |
| テキストシェア | 結果を文章でシェア | — |
| 今日の一匹 | 日付から1種を決めて表示（端末の日付で毎日変わる） | `todayIdx` `renderToday` |
| クイズ | ランダムな2種の睡眠時間をくらべる2択 | `newQuiz` `drawQuiz` |
| 図鑑・発見記録 | 詳細を開く／クイズに出ると登録 | `markSeen` `renderColl` |
| レア度 | 生き物ごとに★1〜3（下のルール） | `rar` |
| 詳細ダイアログ | 豆知識、出典、写真・Wikipedia・動物園の検索リンク | `openDetail` `photoURL` `wikiURL` `zooURL` |
| 言語切替 | 日本語／英語 | `applyLang` |
| シークレット | 隠しキャラクター「マリリン」。起動方法はこの公開文書には書かない | `openSecret` |

### レア度のルール

| レア度 | 条件（どれか1つに当てはまれば） |
|---|---|
| ★★★ | 絶滅種／0時間／1時間未満／19時間以上／脳の半分ずつ眠る／細切れに眠る |
| ★★ | 哺乳類以外／立ったまま眠る／16時間以上／3時間以下 |
| ★ | それ以外 |

## 4. データ設計

`index.html` の `<script>` の中に、3つのデータが書かれています。

### 4-1. 生き物データ `D`（124件）

| 項目 | 意味 | 例 |
|---|---|---|
| `n` / `ne` | 和名／英名 | コアラ / Koala |
| `sci` | 学名 | — |
| `e` | 絵文字 | 🐨 |
| `h` | 1日の睡眠時間（時間） | 0〜20.4 |
| `g` | なかま | mammal / bird / reptile / amphibian / fish / insect |
| `t` | 現存か絶滅か | living / extinct |
| `r` | 信頼度 | A＝学術文献、B＝一般解説、C＝推定 |
| `s` | 出典（`SRC` のキーの配列） | — |
| `k` | 眠り方（任意） | half＝脳の半分ずつ、stand＝立ち寝、micro＝細切れ |
| `m` / `me` | 説明文（日本語／英語） | — |

**件数の内訳（2026-10-08時点）**

- なかま：哺乳類 80／鳥類 16／爬虫類 12／魚類 6／両生類 5／昆虫 5
- 区分：現存 119／絶滅 5
- 信頼度：A 117／B 2／C 5
- 眠り方の記載：脳の半分ずつ 5／立ち寝 4／細切れ 4

### 4-2. 出典辞書 `SRC`（19件）

キーごとに、日本語・英語の出典名を持ちます。`GEN`（一般的な紹介値）と `EST`（このアプリ独自の推定）は、出典一覧には表示しません。

### 4-3. 文言辞書 `T`（各154項目）

画面の文言を `T.ja`（日本語）と `T.en`（英語）で持ちます。HTMLに `data-i="キー"` を付けると、`applyLang()` が文言を差し込みます。

### 4-4. 端末に保存するデータ（localStorage）

| キー | 内容 |
|---|---|
| `sleepH` | 入力した睡眠時間 |
| `sleepLang` | 選んだ言語 |
| `sleepSeen` | 図鑑の発見記録 |
| `sleepQuiz` | クイズの成績 |
| `sleepSecret` | シークレットを見つけたか |

すべて閲覧者のブラウザの中だけに保存され、外部には送りません。

## 5. 仕組みのポイント

- **共有URLの自動切替（`PUBLIC_URL`）**：`*.github.io` で開いたときは、そのページ自身のURLを使います。それ以外（Claude版など）で開いたときは、Claude版のURLを使います。結果カードとシェア文に入るURLは、ファイルを直さなくても正しくなります。
- **色の管理**：色はすべてCSSの変数（`:root`）で管理しています。ダークモードは、端末の設定（`prefers-color-scheme`）と `data-theme` の両方で定義しています。
- **フォント**：Zen Maru Gothic／Zen Kaku Gothic New（Google Fonts）
- **JavaScriptが動かない環境**：ファイルのプレビュー表示などで動かない場合に備えて、`<noscript>` で案内を出しています。

## 6. 守るルール（変更するとき）

1. 文言を足すときは、`T.ja` と `T.en` の**両方**に書く
2. 生き物を足すときは、説明文 `m`・`me` の両方と、出典 `s`・信頼度 `r` を必ず付ける
3. 絶滅種の値は推定であることを、画面上で明示し続ける
4. 外部にデータを送る処理を足さない（アプリ内で「送信しない」と明記しているため）
5. 医療・健康アドバイスと受け取られる表現（睡眠の良し悪しの断定）は避ける
6. シークレットキャラには、実在の人を特定できる情報（名前・誕生日・家族など）を載せない
7. 変更したら、Claude版にも反映するかを判断する
